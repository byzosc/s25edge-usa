## 实际执行的设置

1. `SET DEFAULT LTE BAND`
2. `REMOVE NR5G PRUNE`
3. `REMOVE ONLY NR WHITELIST`
4. `SA/NSA ENABLE`
5. `REMOVE SA PERMIT LIST`
6. ADB 请求正常重启
7. 开机后再次读取网络状态并保存验证快照

中国移动卡按 SIM 1 执行，因此没有切换 `STACK 2`。

## ADB 与 Android 16 的实测差异

### ADB 37 设备列表格式

Google Platform-Tools 37.0.1 在本机输出 `adb devices -l` 时用空格分隔字段，旧脚本按制表符识别而误判无设备。连接解析已改为同时接受通用空白字符。

### Android 16 的 Service Mode 权限

本机明确拒绝：

- shell 直接启动未导出的 `com.sec.android.RilServiceModeApp/.ServiceModeApp`；
- shell 发送 `com.samsung.android.action.SECRET_CODE` 广播。

可行路径是 ADB 打开三星拨号器，并注入 `*#27663368378#` 的按键序列。Service Mode 打开后，UI Automator 可以读取菜单文字，脚本按文字寻找节点中心后点击，不依赖固定坐标。

### 菜单状态复位

每完成一项，Service Mode 会停留在深层结果页。脚本最初误把“Service Mode 仍在前台”当成“已回主菜单”；修正后，每项开始前只关闭 `com.sec.android.RilServiceModeApp`，再由拨号器重新进入主菜单，确保路径确定。

### Windows USB 半连接

初次连接时出现过 USB 复合设备部分端点卡死：MTP 能列出内部存储，但 ADB 和 Samsung Modem 返回 Windows 错误 31。用墙充确认手机充电硬件正常后，重新连接电脑恢复 ADB。详见 `docs/usb-connection-recovery.md`。
