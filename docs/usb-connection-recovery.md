# USB 半连接 / 不充电恢复

## 2026-08-27 本机诊断

当前 Windows 同时枚举到 Samsung USB Composite、MTP、ADB 和 Modem，设备管理器表面状态均为 OK；但实际测试结果不同：

- MTP 正常，可以列出手机的“内部存储”和“内部存储（应用分身）”。
- `adb devices -l` 为空。
- ADB 36.0.2 调试日志在读取 USB 序列号时返回 Windows 错误 31：“连接到系统的设备没有发挥作用”。
- 打开 Samsung Mobile USB Modem 的 COM13 时返回同样错误。
- 用户同时观察到手机停止充电，USB 用途入口出现但无法进入。

结论：不是整条数据链完全断开，而是三星 USB 复合设备处于“部分功能可用、部分端点失效”的状态。先恢复稳定充电和 USB 会话，再做 ADB/5G 操作。

## 安全恢复顺序

1. 从电脑和手机两端拔下数据线，暂停所有 ADB/5G 脚本。
2. 手机不接任何线，按住“侧键 + 音量下”至少 7 秒，看到 Samsung 标志后松手。这是强制重启，不会清除数据。
3. 完全开机后，先接一个确认正常的三星或合规墙充，直接插墙上插座，不接电脑，等待 10 分钟。
4. 如果墙充也不显示充电：
   - 查看是否有水滴/异物警告；若有，立即拔线，让接口朝下自然通风干燥，不能用热风或尖锐物清理。
   - 检查 Type-C 口与插头是否有绒毛、松动、弯针、腐蚀或潮气。
   - 换一套确认正常的充电头和线测试。
   - 仍不充电时停止 ADB 操作，交三星服务中心检查 USB-C 口/充电小板。
5. 只有墙充稳定后，才重新连接电脑：保持手机已解锁，优先换一个电脑 USB 口和一根确认支持数据的线。
6. One UI 7 可到“设置 → 安全和隐私 → 更多安全设置”，暂时关闭“锁定时阻止 USB 连接”。三星说明锁屏超过一段时间后会限制 USB 数据连接，解锁后需要重新插线。
7. 到“开发者选项”：
   - 点“撤销 USB 调试授权”；
   - 关闭再打开“USB 调试”；
   - 默认 USB 配置选择“传输文件 / Android Auto”。
8. 重新插电脑，手机弹出 RSA 指纹时勾选“始终允许这台电脑”，再运行根目录 `check-device.cmd`。

## 不要做

- 在不能稳定充电时刷机、进 Download Mode、改 CSC 或升级系统。
- 用针、金属片或高温热风处理 Type-C 口。
- 为了强行识别而反复卸载 USB 复合驱动；当前 MTP 仍工作，问题不等同于驱动完全缺失。
- 在 ADB 仍为空时运行 5G 恢复入口；脚本本身会等待并安全超时。
